# ZeroGuard AI Development Plan

The project will be built incrementally. Each phase should produce something verifiable before the next phase begins.

## Completed Phases

- Phase 1: repository setup.
- Phase 2: dataset understanding.
- Phase 3: preprocessing pipeline.

## Immediate Next Phase

Phase 4 will train the first Isolation Forest baseline using the processed demo data, then prepare the path for CICIDS2017 training.

## MVP Target

The first working milestone is:

```text
Safe sample data
-> Isolation Forest
-> FastAPI
-> Spring Boot
-> PostgreSQL
-> React dashboard
-> Detection displayed successfully
```

Advanced features such as LSTM, ensemble scoring, CI/CD, and AWS documentation will be added only after the MVP path works.
